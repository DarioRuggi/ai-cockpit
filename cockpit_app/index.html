cloud Workers — Online LLM Providers

Workers are online LLM providers used as specialty workers (translation, image gen, audio) and as fallback when the main 3 agents are exhausted. API keys are stored encrypted at rest using your machine ID + cockpit salt (AES-256-GCM).

build Tools — Local CLI Programs

Tools run local CLI programs (ffmpeg, whisper, pandoc, etc.) for file conversions and transformations. No internet, no API keys, no usage tracking. Binaries are auto-detected on first use; override the path manually if your binary is in a non-standard location.

rule Directives — Global Standing Rules

These rules are prepended to every supplier's context at dispatch — Claude, Gemini, Ollama, and Workers alike. Write once; applies everywhere. Per-project rules stay in each project's COCKPIT.md and layer on top of these.

Per-supplier overrides — optional; leave blank to use full/compact above
When set, this text is used for that supplier instead of full/compact — tune per model.

Note: Workers receive directives only when answering a text task directly. Image / audio / video generators are never given a directive preamble (it would corrupt their output). Workers invoked as sub-tasks by another agent inherit that agent's directive-informed instructions.
